# 风险、SLO 与验收门

## 风险登记

| 风险 | 触发信号 | 处置 | 停止条件 |
|---|---|---|---|
| 范围膨胀 | 第 2 天仍未完成表和状态机 | 冻结为一条物流异常主路径 | 不再新增类目/渠道 |
| AI 输出不稳定 | Schema 校验失败或动作越权 | Mock 默认、严格枚举、失败转人工 | 任一非法 Decision 可执行 |
| 跨服务不稳定 | Feign 超时/服务未启动 | Adapter + 超时 + 固定种子替身 | 无替身无法演示 |
| 重复退款 | 同一幂等键多条成功记录 | DB 唯一约束 + 条件更新 | 重复测试失败 |
| 工作流卡死 | Step 长时间 RUNNING | checkpoint + 恢复扫描 + 上限转人工 | 无法从中断恢复 |
| 权限越权 | 用户可读他人 ticket | 网关身份 + 服务归属校验 | 任一越权用例通过 |
| 文档夸大 | 计划被写成已完成 | 状态标签和证据索引门禁 | 无来源的结果数字 |

## 测试矩阵

| 层级 | 用例 | 命令/操作 | 期望 |
|---|---|---|---|
| 单元 | 状态迁移、Policy 分支、Decision 校验 | `mvn -pl bookmall-after-sale -am test` | 全部通过 |
| 单元 | 重复退款、重复消费 | 同一 key 调用两次 | 一次副作用 |
| 集成 | MySQL 表、唯一索引、Outbox | Docker 基础设施 + SQL 更新脚本 | 记录可查 |
| 契约 | Mock LLM、工具结果、RAG | 固定 JSON fixture | Schema 稳定 |
| 端到端 | 自动退款/人工审批 | Gateway JWT + curl 脚本 | 两条路径闭环 |
| 安全 | 用户 A 读 B、普通用户审批 | 带不同 JWT 调用 | 拒绝越权 |
| 故障 | 工具超时、Worker 中断、MQ 重复 | 注入开关/重放消息 | 降级或恢复 |

## 七日验收门

第 1 天：领域模型、状态矩阵、SQL 草案和基线命令。  
第 2-3 天：售后服务可启动，创建/查询/审批/退款核心单测通过。  
第 4 天：Mock AI、工具白名单、RAG 证据可返回。  
第 5 天：浏览器或 curl 跑通两条路径，权限和审计可查。  
第 6 天：幂等、Outbox、恢复和故障测试通过。  
第 7 天：录制演示、整理证据、更新简历和面试问答；不通过则冻结在最后一个通过门。
