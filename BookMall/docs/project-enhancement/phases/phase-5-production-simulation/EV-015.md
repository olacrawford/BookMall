# EV-015 前端售后控制台接入

## 状态

`verified`（本地构建与接口代理验证）/ `simulation`（后端 Mock 结算与物流）

## 结论

Vue 3 前端已接入售后中心：登录用户可查看自己的售后单、创建新工单、打开详情和 AI 证据；`APPROVER` 用户可加载待审批队列并执行批准/驳回。构建通过，Vite 到 Gateway 的代理链路实测可用。

## 环境

- macOS，Node.js（Vite 6），Vue 3.5。
- `bookmall-auth`（8060）、`bookmall-gateway`（8080）、`bookmall-order`（8050）、`bookmall-after-sale`（8093）本地运行。
- 前端开发服务器：`http://localhost:5173`，`/api` 代理到 `http://localhost:8080`。

## 改动范围

- `front/src/views/AfterSaleView.vue`：售后中心页面，包含创建表单、我的售后单、详情、AI 分析、审批待办。
- `front/src/api/bookmall.js`：新增 `afterSaleApi`，覆盖 `GET /api/after-sales`、创建请求头 `Idempotency-Key`、详情、分析、审批队列、批准、驳回。
- `front/src/router/index.js`：新增 `/after-sales` 登录保护路由。
- `front/src/App.vue`：侧边栏增加“售后中心”。
- `front/src/utils/session.js`：登录态规范化时保留 `role`，用于控制审批队列展示。

## 验证命令与结果

```bash
cd front && npm run build
```

实际：`97 modules transformed`，`vite build` 成功，生成 `dist/index.html`、CSS 和 JS bundle。

```bash
curl http://localhost:5173/after-sales
curl -H "Authorization: Bearer <JWT>" http://localhost:5173/api/after-sales
curl -H "Authorization: Bearer <JWT>" http://localhost:5173/api/orders
```

实际：SPA 入口正常返回；`/api/after-sales` 经 Vite 代理返回 `code=200`，当前用户 102 条售后单；`/api/orders` 返回 2 条订单。创建、详情、AI 分析和审批接口与后端 curl 验收链路一致。

## 限制

- 已通过 Chrome 无头浏览器完成真实页面操作验收：登录 `ph5_user`，创建低金额售后 `afterSaleId=1011` 并查看详情/AI 分析，创建高金额售后 `afterSaleId=1012` 并在页面批准；已保存列表、详情/分析、审批队列 3 张截图。未录制人工视频。
- 页面展示的金额、物流、AI 决策仍来自 Mock 本地链路，不代表真实支付或真实模型。
- 审批队列只展示带 `afterSaleId`/`orderId` 的有效任务，避免把阶段 3 的 1000 条性能种子任务直接堆到页面。
