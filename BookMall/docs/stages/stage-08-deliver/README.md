## 面试沉淀

最终简历候选：

```text
基于 Spring Cloud Alibaba 构建 AI 售后智能运营平台，实现售后工单、AI 决策、规则引擎、人工审批、退款与订单状态联动闭环；LLM 仅产出结构化建议，资金操作由 Policy + Workflow 强制执行，并通过幂等键、Outbox 与审计日志保证可重复、可追溯。
```

面试问题：

1. 如果只让你讲一个亮点，你讲哪个？

   回答重点：AI 决策与业务执行隔离，最能体现企业级思考。

2. 如果面试官说“这就是 AI 客服”怎么回应？

   回答重点：强调这是工单系统：有状态、审批、退款、审计、流程恢复，聊天只是入口。

3. 如果被要求现场设计新售后场景怎么答？

   回答重点：先画场景 -> 找出受影响实体和状态 -> 定义 AI 输入/决策 -> 定策略和审批 -> 定幂等与审计。

主动讲失败场景：

```text
系统上线后出现重复退款。我的设计里用 refund_no 唯一和状态检查，因此第二次请求不会创建新退款，同时审计记录了第一次执行。
```
