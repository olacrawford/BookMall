## 面试沉淀

简历候选：

```text
通过业务幂等键、Outbox/MQ、工作流步骤落库与恢复扫描处理重复退款、消息重复消费和流程中断，保证闭环可重复执行。
```

面试问题：

1. 退款成功但 MQ 没发出去怎么办？

   回答重点：业务和 outbox 同一事务写入，worker 异步发送并重试。

2. 消息被消费两次怎么办？

   回答重点：根据 `event_id` 或业务幂等键判断，已处理直接返回。

3. 流程跑到一半宕机怎么办？

   回答重点：流程步骤落库，扫描器按 `next_retry_time` 恢复未完成步骤。

主动讲失败场景：

```text
退款成功、订单通知失败、审计写入失败。通过最终一致性事件补偿，最终订单售后状态完成，审计也能补到。
```
