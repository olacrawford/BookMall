## 使用规则

1. 按顺序从 Stage 01 开始。
2. 每个阶段文件夹内的 `README.md` 是执行手册。
3. 先完成任务，再跑验收清单。
4. 验收不通过时，不进入下一个阶段。
5. 每阶段完成 `PIKE.md`，并把面试素材同步到 [简历与面试](../../简历与面试.md)。
6. 如果觉得 README 读不懂或者无法照做，说明该阶段文档不合格，先补齐文档，不写下一阶段代码。
